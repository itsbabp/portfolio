# Portfolio site

- `index.html` - page shell (change the title and description at the top)
- `content.js` - ALL your content: logo, name, portrait, links, about, projects, photos
- `style.css` / `script.js` - look and behaviour
- `images/` - put resized JPEGs here (long edge ~1600 px, sRGB)

Portrait: save it as `images/portrait.jpg`, then in `content.js` set `portrait:'images/portrait.jpg'`.

If you use a custom domain, keep the `CNAME` file GitHub created. Do not delete it.
