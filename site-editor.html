Welcome

Everything you write on your site, editable from one page.

01Click Open site folder and pick the folder that contains index.html.
02Change what you like in the tabs, then click Save.
03Refresh your preview, then commit and push with GitHub Desktop.

Saving rewrites content.js — your own comments in it are replaced by standard ones, and Git history keeps the old copy, so you can always undo in GitHub Desktop. Works in Chrome and Edge. Elsewhere, "content.js only" downloads the new file for you to copy over the old one.
